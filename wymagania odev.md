# Wymagania ODEV

| Wymaganie | Kryterium odbioru |
| --- | --- |
| Hosting i baza | EOG preferowany; udokumentowana lokalizacja, kopie, podprocesory |
| Szyfrowanie | TLS w transmisji; szyfrowanie danych i kopii adekwatne do ryzyka |
| Dostępy | role, zasada najmniejszych uprawnień, MFA dla administracji i mediatorów |
| Logi | logowanie zmian, pobrań, wysyłek i dostępu; ochrona integralności |
| Załączniki | lista typów, limity, skan malware, nazwy bez danych wrażliwych |
| Zaproszenia | jednorazowe tokeny, ważność, brak danych sporu w URL i temacie |
| Usuwanie | automatyczne terminy i możliwość udokumentowanego usunięcia także kopii |
| Kopie bezpieczeństwa | test odtworzenia, harmonogram i retencja kopii |
| Środowiska | brak danych produkcyjnych w testach; dane syntetyczne |
| Incydenty | SLA powiadomienia, kontakt 24/7, zachowanie logów |
| Podprocesorzy | uprzednia informacja i prawo sprzeciwu zgodnie z DPA |
| Eksport i zakończenie | pełny eksport, usunięcie danych, potwierdzenie, ciągłość działania |
